# Pharma Impurity Limit Calculator

This Streamlit app calculates impurity limits for **drug substances** and **drug products** according to international guidelines:
- ICH Q3A (Drug Substance)
- ICH Q3B (Drug Product)
- ICH M7 (Mutagenic impurities)
- Nitrosamine categories (US/EU)

## 🚀 Features
- Input drug name, category, market, dose, and treatment duration
- Automatic calculation of reporting, identification, and qualification thresholds
- Mutagenic impurity limits (ICH M7)
- Nitrosamine category limits
- Results displayed in a clean interactive table
